# JaMusic

JaMusic is a React + Vite website for discovering independent music. It includes a responsive music-discovery interface, search, Supabase track loading, and audio playback. The previous full vanilla-JavaScript experience is kept at `/legacy.html` while the React site is developed.

## Local development

```sh
npm install
cp .env.example .env
```

Fill `.env` with your Supabase **Project URL** and **publishable key** (Supabase Project Settings → API):

```dotenv
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

Then start Vite:

```sh
npm run dev
```

Vite prints the local URL. The `.env` file is ignored by Git. Vite exposes only `VITE_*` variables to browser code, so only a Supabase publishable key belongs here—never use a secret/service-role key in frontend code.

The website loads `tracks` and associated `profiles` from Supabase. It expects the `audio_url`, `cover_url`, title, duration, genre, album and created-at fields used by the project. Configure database Row Level Security and storage access policies in Supabase. This repository does not include the referenced `setup.sql`.

## Cloudflare Pages

Use these settings in the Cloudflare Pages build configuration:

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Environment variables:** `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY`

The production build uses Vite and React; `dist` is generated by the build and should not be committed.
